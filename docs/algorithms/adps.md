# ADPS：公开预印本的独立响应适配

## 来源和复现边界

实现依据为 Lei 等公开于 2024-10-08 的
[arXiv:2410.05787v1 全文](https://arxiv.org/html/2410.05787v1)，题为
*An Adaptive Dual-Domain Prediction Strategy based on Second-order Derivatives for Dynamic Multi-Objective Optimization*。
已查看全文及第 III 节算法 1–3、公式 (5)–(10)，不是仅按摘要实现。

**这里只按该公开 2024 预印本适配，未核验期刊最终版本。**
后续版本标题和内容可能变化；[正式期刊 DOI](https://doi.org/10.1109/TEVC.2025.3594549)
仅用于区分来源，不能据此将本实现称为完全的 2026 TEVC 期刊复现。
`info.json` 按组件目录要求标记 `name=ADPS, year=2026`，不表示代码使用了期刊最终方法。
这也不是作者源码、原始实验结果或性能等价性验证。

## 调用与发现

```python
from algorithms.response_strategy.ADPS import ADPS

strategy = ADPS()
result = strategy.response(population, problem, algorithm)
```

`info.json` / `config.json` 支持现有目录自动发现、默认参数读取和中文参数标签，
无需修改 registry 或全局依赖。预测、聚类与逆映射只使用 NumPy；
排序和种群数据结构复用现有接口。支持 `algorithm=None` 和 `seed=None`；
有整数 seed 时，同样的输入和响应序列可重复。

响应输入应为已评估的旧环境种群。检测由静态优化器负责；
响应不再次探测，不调用静态优化器的私有变异/选择方法，也不读取真实 PF/PS。
可与 NSGA-II、MOEA/D、SPEA2、RMMEDA 独立组合；原预印本实验的静态优化器是 MOEA/D。

## 机制和明确的适配选择

| 机制 | 本实现 | 来源/适配边界 |
| --- | --- | --- |
| 双域关键点 | 对约束非支配解的决策 X 和旧目标 F 分别在线聚类 | 算法 2；不是单个总体中心外推 |
| 初始中心 | 均值加每个目标的最小值对应解，K=M+1 | 原文 M 个边界点的取法不唯一，明确选择目标极小点 |
| 时间关联 | 历史中心按整体平移暖启动，保持槽位关联 | 防止独立聚类标签置换；这是实现选择，不宣称作者使用同一方法 |
| 二阶预测 | 各域、各簇、所有维度使用速度及加速度 | 公式 (7)、(9)，再按当前簇标签平移簇内解 |
| 方向反馈 | 正弦差内积负时三项加权平滑，否则保留当前加速度 | 公式 (8)、(9)，权重具体值为实现选择 |
| 随机扰动 | 当前解到前一集合最近距离/max 最近距离，控制随机向量模长 | 公式 (10) 的标量上界解释，不是固定高斯噪声 |
| 目标逆映射 | 有限预算的有界坐标搜索，最小化真实目标欧氏距离 | 公式 (5)；搜索器/预算未由 v1 唯一规定，不是查表或无计数拟合 |
| 自适应分配 | 收敛非支配解的双域种子最近邻归属计数，更新后归一化 | 算法 1 的接口适配，非精确谱系追踪 |

每次在线遍历按最近中心分配解并以递增样本数更新均值。
不对重复中心做矩阵求逆；空簇保留其锚点，小种群仍保留 K 个槽位。
历史最多保存 5 组 X/F/双域中心，数组独立复制，不修改输入个体、旧 F/G 或 rank。
同一 `problem.t` 重复调用替换末快照，不制造历史时间步。
新问题对象、维度/边界/种群规格变化，或问题 reset 导致 t/评估数回退时清空历史和权重。

### 二阶导的因果索引

原文公式 (7)、(8) 包含未来索引，与只使用历史的说明不完全自洽。
这里按**已观测快照序号** s 作因果重编号，环境等间隔的差分为：

\[
v_s=C_s-C_{s-1},\qquad a_s=C_s-2C_{s-1}+C_{s-2}.
\]

三个已观测加速度足够时，计算每个簇的

\[
q_s=\langle\sin(a_s)-\sin(a_{s-1}),
                 \sin(a_{s-1})-\sin(a_{s-2})\rangle.
\]

若 q_s<0，使用 `0.5*a_s + 0.3*a_(s-1) + 0.2*a_(s-2)`；
否则使用 a_s。三项系数递减且和为 1；v1 没有给出唯一数值，不能称它们为原文指定参数。
预测位移是 v_s 加该加速度项，决策域与目标域独立计算。
不把向量 sin 擅自改为余弦方向判别，也不使用预测未来加速度冒充观测量。

第 III-C 节正文描述三环境历史，而算法 3 写 `P>3`。
这里三快照开始二阶预测，五快照才有三次加速度并启用完整方向反馈。
更短历史或响应预算不足时按算法 3 的冷启动思想：约 90% 旧决策加 10% 均匀随机解，
整数四舍五入后至少一名随机解（N=1 时只能随机一名），然后在新环境重新评估。

扰动采用随机单位方向；模长为 `scale * U(0,1) * d_i / max(d)`，
d_i 为到前一集合的最小欧氏距离。`scale<=1` 保持公式 (10) 上界。
原式未指定随机方向与坐标量纲处理，这里直接在各域原始坐标中使用该模长。
零最大距离时扰动为零；d_i=0 时同样为零，避免原式退化的除零/严格正下界矛盾。
决策预测及逆搜索均裁剪到 xl/xu，固定维度不搜索；目标预测不强制非负。

### 双域权重和贡献

权重初始各 0.5。每次有上一轮双域种子时，先用输入种群的旧 F/G 做约束非支配排序，
再在按决策边界跨度缩放的空间中将非支配解归给距离最近的双域种子集合。
等距各计半票，避免重复中心/重复决策产生顺序偏置。
这不需要给静态优化器新增谱系字段，但它是**最近邻贡献代理**，不是真实后代来源；
尤其在两个域生成近似相同决策时，不能可靠区分因果贡献。

目标域票数较多时给 objective_weight 加 lambda；否则给 decision_weight 加 lambda，
平票按算法 1 的 else 分支。随后两权重归一化，避免原文只递增导致总和超过 1。
原算法 1 的 PS/PF 分配行把 w_o / w_d 标签交叉，本文实现遵循上下文语义：
decision_weight 分配决策预测，objective_weight 分配目标逆映射。
按 N 四舍五入并保持总数严格为 N；预算可执行双域映射且 N>=2 时每域至少一名，
N=1 选择较大权重域。预算限制可能减少目标域配额，见下节。
冷启动没有双域贡献，不虚构票数或学习权重。

### 逆映射、约束和预算

先评估 N 名决策域候选，作为映射初始池；按原始目标距离选取映射初解。
约束遵守框架语义 `G>0` 为违反：可行优先，不可行之间最小化总正违反量，
可行解之间最小化到预测目标的欧氏距离。约束排序、G、feasible、constraint_violation 全部保留。
这是预印本无约束方法面向 FlexDMO 约束问题的扩展；不保证必然找到可行解。

逆映射每迭代对一个坐标提出正、负两次有界搜索；该坐标无改善则减半步长，
下轮转到下一坐标。有限预算可能不足以到达不可达目标或穿越非凸约束，
因此只称近似映射，不称全局逆解。预测目标不会直接写入实际 F。

**所有实际函数求值都通过 `Population.update_objective_constrain(problem)`，
进而调用 `problem.evaluate(X)` 的默认 `need_count=True`，每行计一次。**
代码不直接调用 `_evaluate_objectives` / `_evaluate_constraints`，不手动增减计数。
返回种群复用已评估的决策候选和映射结果，不重复评价。
冷启动成本为 N；双域阶段成本为 `N + 2*N_objective*I_active`，
I_active 是迭代中落在非固定坐标上的次数；批大小只影响控制响应粒度，不改变预算。
`last_inverse_evaluations` 记录映射搜索实际计数，不包括共享初始池 N。

`inverse_iterations` 是**平台选择的迭代上限，不是原论文的固定数值**，v1 未明确规定。
默认 3，在平衡双域、非固定坐标且额度充足时响应约消耗 4N，
而配置 20 则可能达到 21N。20 仍可设置，但不会绕过响应局部额度限制。
根据 `evaluate_time`、`initial_convergence` 和 `change_each_evaluations` 计算
距离下一个 FE 边界的剩余行数 R，映射额度为 `max(0, R-2N)`：
扣除 N 名基础候选，并为后续一代静态搜索预留 N。
目标域人数不超过 `floor(额度/2)`，轮数不超过 `floor(额度/(2*N_objective))`。
这也考虑检测时已经越过前一 FE 边界的超额；所有减少的搜索轮数仍可观测、可测试。

额度不足两次评价时，维持约 90/10 的有计数冷启动，继续归档历史，
不将无搜索的查表结果称作完整目标逆映射。通常 tau=3 允许一轮映射并留一代静态搜索；
tau<=2 可能持续进入预算冷启动。tau=1 时仅重新评估 N 名种群已经消耗整个间隔，
因此框架中不能保证响应后仍有一代静态搜索；这里不通过漏计评估规避该事实。
`last_inverse_iterations` 记录本次获准轮数上限，`last_budget_limited` 标记裁减/预算回退。

**上述限制不是严格全局 FE 预算。** FlexDMO 仍按环境总数终止，
静态优化器的整代评估可能越过 FE 边界；响应回退和不同域配额也改变实际总评估数。
不能把“映射计入预算”进一步宣称为与论文或其他方法严格同 FE 预算复现。
公平比较必须额外记录/约束实际 FE 和静态搜索代数，而不能只匹配环境数。

已确认 `Problem.evaluate(..., need_count=False, t=None)` 可能消费 need_change 并推进 t；
因此逆映射**从不使用 False**。有计数评估在当前 t 下进行，可能设置 need_change，
但不会自行推进环境。响应不清除 pending 标志、不回滚评估次数，也不改 `_update_time`。
环境只能由下一次静态优化器的无计数检测推进。

每次聚类遍历、分块距离计算、逆映射迭代及每个评估批前调用 `algorithm.control_process()`。
pause 使用现有阻塞/恢复 hook；stop 中止后续评估，返回输入副本，
不发布本轮部分历史/权重，但已经消耗的评估仍计入预算。
停止结果可能仍含旧环境 F/G，仅用于让已停止的优化器退出，不应视为成功完成的响应。
