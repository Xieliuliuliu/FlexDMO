# VARE 响应策略（2026）

这是 VARE 的**响应机制适配**，不是作者完整 VARE/VARE_MOEAD 的逐行移植或性能复现。静态优化器仍由 FlexDMO 选择：NSGA-II、MOEA/D、SPEA2、RMMEDA 均可调用 `response(population, problem, algorithm)`。仅依赖 NumPy 和框架已有种群/排序接口，不新增全局依赖或修改注册表；目录内 `info.json`（VARE、2026、中文参数标签）及 `config.json` 供现有自动发现使用。

## 实现机制

1. 为每个参考方向保持一条**环境级决策轨迹**。按旧环境缓存目标值进行理想点平移、余弦方向关联，存档后才在当前环境重新评价；不会把评价次数、探测样本或种群行号当成时间序列。相同 `problem.t` 再次调用不增加历史，也不更新策略存活记录。新的问题对象、倒退的环境时间或评估计数、规模/维度/边界变化会清空不兼容状态。
2. PCA 对**单个方向跨环境的决策矩阵**进行均值中心化及 SVD，选择累计解释方差达到 80% 的最少主成分。降维空间拟合带截距的联合 VAR(5)：每个分量同时使用所有分量的全部滞后项，保留跨变量系数，再用 PCA 基与历史均值重构。这不是种群质心的独立单变量 AR。
3. 按作者代码保留三个阶段：首段历史仅 EAH；2–19 段历史中被选为预测的方向使用一步线性外推，加标准差 `||x_t-x_(t-1)||/(2√D)` 的单个高斯标量扰动；默认第 20 段历史开始 PCA/VAR。`4*lag_order` 门槛不会为短 smoke 测试而删除。若某方向 SVD/求解出现数值异常，只对该方向回退线性预测；常值历史直接返回常值，主成分数为 0。
4. EAH 按预印本式 (4)–(7) 计算同一旧决策重新评价前后的相对目标变化 ΔF，以及新环境重新关联代表与旧代表之间的相对决策变化 ΔX，分母均加 `1e-6`。将绝对决策差展平做置信水平 0.95 的右尾单样本 Student-t 检验；无显著决策移动时 η=20，否则 `η=20*max(exp(-(ΔF+ΔX)),0.1)`，范围 [2,20]。单样本无法作 t 检验，保守视为不显著；全零差异不显著，正的零方差样本按极限情形视为显著。Student-t 尾概率用不完全 beta 连分式计算，不需要 SciPy。
5. 对新环境重新关联的决策做边界感知多项式变异，每坐标概率 `1/D`。不强迫每行变异，零宽边界不变异。预测后采用作者的“上界反射→下界反射→最终截断”修复，额外处理非有限决策输入。
6. 将已重新评价的旧代表与候选按方向做 Tchebycheff 比较，严格改善才算候选存活。约束扩展使用可行性优先；不可行对不可行时比较总正约束违反量，等违反量不根据目标伪判改善。预测/EAH 的尝试及存活记录按最近 `L=lag_order` 个环境滚动，使用成功**率**而非成功数量计算式 (8)，双方都无成功时 π=0.5，并按作者代码将 π 限制到 [0.1,0.9]。实际线性预测也归入预测尝试。

## 与作者完整版的重要差异

- **估计器不等价**：这里求解 `min ||Y-ZB||² + regularization*||B_slopes||²`，截距不惩罚。这是固定单位创新协方差、零均值各向同性高斯斜率先验下的 **ridge posterior mode / MAP**，通过增广最小二乘求解；不抽取后验系数或创新，不拟合完整 Bayesian 协方差分布，不复刻作者 `bayesvarm → estimate → forecast` 的后验预测，更不实现 MCMC/Gibbs。`regularization=0` 退化为联合 OLS。应报告“NumPy ridge-MAP 适配”，不能写成作者 Bayesian 估计的数值等价复现。
  作者源码没有指定 ModelType、抽样次数或 MCMC 设置。[MathWorks bayesvarm 文档](https://www.mathworks.com/help/econ/bayesvarm.html)显示默认 diffuse prior；[estimate 文档](https://uk.mathworks.com/help/econ/conjugatebvarm.estimate.html)说明可解析时使用闭式 Bayes 估计、否则使用 Gibbs sampler。因此不能把此提交的默认 estimate 一概称为“必然执行 MCMC”，但这里明确没有复刻任何作者 Bayesian/MCMC 路径。
- **静态引擎不等价**：预印本/`VARE.m` 采用 SPEA/R 风格的逐代多样性选择和 RM-MEDA 繁殖；`VARE_MOEAD.m` 使用 MOEA/D+DE、邻域替换和自己的理想点。此模块只移植变化响应，不替换静态引擎、不执行 DE、不引入邻域或 SPEA/R 逐代选择；响应内部参考方向及逐方向候选比较是独立的，不能与当前静态 MOEA/D 的内部权重宣称共享。
- **环境新理想点**：候选比较只用本次重新评价父代和子代的目标最小值，不携带上个环境的理想点；这是框架适配，区别于作者 MOEA/D 实现保留并更新其 Z。
- **论文与源码的 EAH 差异**：作者两份源码停用了 t 检验，并将 ΔF 计算在重新匹配后的目标上；这里保留预印本的显著性门控，ΔF 比较同一决策的旧/新目标，ΔX 则来自方向重新关联，避免仅有目标平移时自动增加超变异强度。
- **约束和退化情况**：作者实验/响应代码主要面向无约束固定维度问题。这里关联时优先可行代表；全不可行时使用最低违反量代表。理想点零向量、余弦/距离并列使用确定性次序；种群可重排、代表允许重复。小于目标规模的输入通过关联重复代表，过大的输入按方向取代表，空输入生成有界随机种群；不新增共享工具。
- **参考方向与历史上限**：2 目标等距方向；多目标用确定性单纯形格点及最远点筛选保持准确目标种群规模，不照搬作者 UniformPoint 可能调整 N 的行为。历史默认最多保留 100 个环境，作者 EP 默认累计全部环境。只有当前环境最终输入代表进入历史，不采集响应后的每次评价。
- **没有性能等价结论**：数值单元测试及端到端冒烟证明接口/机制可执行，不证明原论文 MIGD/MHV 或速度优势，不保证任意优化器与完整作者算法表现等价。

## 参数、评价和控制边界

| 参数 | 默认值 | 范围/意义 |
| --- | --- | --- |
| `lag_order` | 5 | 正整数；VAR 阶数，同时是自适应存活窗口 |
| `explained_variance` | 0.8 | (0,1]；PCA 累计解释方差 |
| `regularization` | 0.000001 | 有限非负数；固定高斯斜率先验强度，0 表示 OLS |
| `history_length` | 100 | 正整数且至少 `4*lag_order`；环境存档上限 |

正常已评价、有界非空输入，每次变化响应计数评价 `2N` 个个体：旧代表重评价 N，候选评价 N；不再额外评价最终选择结果。空种群计数 N，同一环境重复调用计数 N 但不新增历史。未评价或需修复的原输入缺少可信旧环境目标，先计数评价该输入规模，再进行正常响应，并在 `last_diagnostics.old_baseline_known` 标识此兼容回退；不能据此宣称观察到了真实旧/新环境严重程度。

所有评价使用当前环境的普通有计数接口。不调用 detection，不传 `need_count=False` 触发环境推进，不主动写 `problem.t`。预算到达阈值时框架可能设置 `need_change`，仍由外层优化器的下次检测处理；本次内部批量评价不跨环境。输出重新设置 F、原始 G、可行性、总违反量并完成约束非支配排序，不沿用旧评价状态。当前静态引擎仍要求固定决策/目标维度，历史重置不是支持动态增减维度的保证。

暂停/停止使用可选 `algorithm.control_process()`：响应入口、参考方向循环、每个 VAR 方向及关键评价前检查，评价每批至多 64 个个体。无 hook 或 `algorithm=None` 均可调用。hook 返回 False 时停止后续计算/评价，返回输入种群的副本，回滚本次环境历史、成功记录、诊断和 RNG；已消耗评价保留计数，外层优化器负责退出。暂停阻塞/恢复语义由 hook 实现。单个 NumPy SVD/BLAS 调用或 `problem.evaluate` 批次不能在内部抢占，停止最迟在下一个检查点生效。

`last_diagnostics` 提供本次每方向的 `eah/linear/pca_var`、主成分数、预测尝试、候选存活、更新后的预测概率、ΔF、ΔX 和 η，用于机制审计；常值 PCA/VAR 的零主成分不是通用 AR 替代。

## 专属验证

响应发生普通异常时也恢复历史、自适应状态与随机数状态，随后重新抛出原错误；
已经完成的函数评价不会回滚。不可行解之间严格比较总违反量，
`1e-12` 仅用于可行判定，不作为忽略真实违反量改善的阈值。
界面与批量参数支持 `regularization=0`；负值由组件构造器拒绝。

在仓库根目录运行：

```bash
.venv/bin/python -m unittest discover -s tests -p 'test_vare.py' -v
```

覆盖联合跨变量 VAR 系数和截距、滞后顺序、PCA 降维重构、秩亏/常值、Student-t 尾概率、目标平移与决策移动的 EAH 区分、成功率自适应、反射边界/固定坐标、小/空/不匹配种群、输入不修改、约束翻转重评价、同环境重复调用、计数不推进环境、种子重现、数值回退、自动发现与中文参数，以及 4 静态引擎 × 无约束/有约束实际优化流程。

专属长历史测试使用默认 5 阶 VAR 和 24 个不同环境存档，确认前 19 段不拟合完整 VAR、第 20 段起真正执行 PCA+联合 VAR，核对主成分数和实际滚动成功率。另有停止入口零评价、评价批间停止、VAR 方向间停止/状态回滚测试。短历史集成 smoke 不触发默认完整 VAR 是预期行为，不能替代此长历史验证。
