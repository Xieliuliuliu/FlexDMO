# FlexDMO 使用说明

安装后运行 `python main.py`，macOS 可双击 `Start-FlexDMO.command`。
安装命令见项目根目录的 [readme.md](../readme.md)。

## 运行与界面

- 注册表现有动态策略、搜索算法及问题自动发现，无需复制算法。
- 下拉菜单统一使用标准列表绘制和显式选中色，避免 macOS 下选中文字白底白字；
  算法、图表、预设和组件类型均支持鼠标及键盘选择。
- 切换算法时保留其他组件的参数，同一组件切回后恢复上次输入；
  仅点击“恢复原算法默认参数”才重置当前组合。图表标题绑定实际结果，
  与待运行的选择分开；回放、刷新保留缩放，工具栏主页恢复当前帧自动范围。
- 默认选择 D-NSGA-II-B / NSGAII / CDP1，并明确应用快速试跑参数：
  20 个体、5 环境、变化间隔 3 代、6 决策变量；参数页可恢复原默认配置。
- 独立优化子进程，暂停/继续、合作终止及两秒超时强制终止；异常记录到日志。
- 默认不保存运行数据，普通重跑/关闭不询问是否保存；实时图与回放只用本次会话的内存。
  重跑、关闭后不保留未保存结果，需要保留请点击“保存结果”。
  可勾选“自动保存结果”，结束后后台原子保存到 `results/autosaved/`；
  此模式下重跑前也先保存旧结果，保存失败保留旧结果、不启动。
  “视图 → 打开自动保存目录”可查看文件，“打开结果”可加载回放。
  自动保存模式保护未保存数据；运行中关闭仍确认，避免误终止任务。
- 默认完整快照，实时绘制最新帧（最多约 10 Hz），运行结束后逐帧/定速回放。
  可选“环境末帧”，实时替换同环境副本，结束后每个环境只回放末帧。
  不改变算法内部历史；轻量模式减少界面副本和文件，不保证整个进程内存有界。
- 右侧历史使用稳定的环境按钮，不使用表格选中项接口，避开已观察到的 macOS
  原生无障碍选中项查询崩溃路径。点击跳到该环境最近快照，同时暂停自动播放；
  时间轴仍可逐帧回放。方向键/Home/End 移动焦点，Enter/空格激活。
  重跑和替换结果会使旧历史事件失效，连续点击合并绘图；不改变算法或存储默认值。
  浅色主题显式设置文字和控件颜色，保持系统深色模式下可读。
- PF、PS、IGD、约束违反量四类图表；PF 不可行区域显示灰色。
  默认同时显示 PF / PS / IGD，可一键加入约束图或单图查看；宽窗口网格布局，
  窄窗口纵向滚动，各图同步同一回放位置并独立保留缩放。
  多于两个目标时 PF 显示前两个目标的二维投影；PS 橙线为真实 PS 的逐维中位数。
  IGD 使用当前回放位置之前、每个环境的最新可行种群，不读取未来快照。
- Qt 原生 Matplotlib 缩放、平移、图像导出工具栏。
- 设置和运行历史面板可拖动、隐藏和浮动；诊断信息默认隐藏，
  需要时在“视图 → 显示诊断信息”打开。窗口变窄时自动隐藏历史面板，
  可用工具栏重新打开。最小窗口 700×520；参数页采用可滚动的上下标签表单。
- JSON 结果保存/读取使用后台线程；原子保存，加载失败保留现有数据。
  保持原结果 schema，支持旧版仅决策值文件。
  缺失目标或约束时按记录的环境重算，已有目标不会因重算约束而覆盖。

## 批量实验：少配置地运行

1. 顶部选择“批量实验”，勾选策略、搜索算法和问题。输入名称可以筛选，
   “全选可见”只选当前筛选范围。“当前组件参数”编辑蓝色选中的组件。
2. 选择“快速检查”或“论文实验（可编辑）”预设，也可“沿用当前测试配置”。
   共享的决策变量数、种群、环境数、n/tau、seed 在实验页统一设置，
   高级窗口仅显示其余组件参数，避免同一参数有两处互相覆盖。
3. n/tau 支持逗号列表或 `5:15:5` 包含终点的范围。重复次数自动生成独立种子：
   第一次 seed=起始种子，第二次加 1，同次重复的所有算法使用相同 seed。
4. 界面预估任务数，“更新任务”可预览；“开始实验”总是从当前可见配置重新生成，
   不会运行过期的任务列表。最多 10,000 任务，超过 200 先确认；并行上限 8，默认 1。
5. 可以暂停/继续、终止全部，切换工作区不终止任务。失败任务不会阻塞队列。
   默认不创建目录或写文件；任务完成后可双击内存回放，关闭或新批次后不保留。
   内存回放中的结果也可在测试页手动保存。运行前勾选“保存实验结果”才写所选方式的快照。
6. 勾选保存时，每次运行创建独立目录，保存快照 JSON、`runs.csv`、`summary.csv`、
   `statistics.xlsx` 和 `manifest.json`，不覆盖前次实验。未勾选时仍显示汇总统计，
   也可点击“导出统计”手动写出 CSV、Excel 和清单，不写原始快照。
   统计显示 MIGD / MGD / MHV 的均值与样本标准差，以及平均可行率。
   仅完整成功的重复计入汇总，失败/取消单列；IGD=∞ 不会被忽略或伪装成 0。
   MHV 使用原仓库约定的 `当前真实 PF 最大值 + 0.5` 参考点，只支持二维目标；
   更高维度显示未支持，而不是编造指标。
7. “保存实验配置 / 加载实验配置”保存组件名称、参数扫描和高级参数，可跨会话复用。
   加载时先验证全部组件和参数，失败则保留原配置。
8. “比较结果”按问题参数与预算分组，支持末帧 IGD、可行率、同环境/seed 的 PF、重复 MIGD。
   每条线/每个点代表一次独立运行，不冒充均值或显著性结论。
   无穷大明确计数，算法参数或单文件代码指纹不同的变体不合并，读取文件在后台进行。

合作终止时尽可能保留部分历史；仅勾选保存时写文件。若任务不响应、两秒后强制终止，
则可能没有部分历史或文件。
关闭程序会提示是否终止运行中任务。自动统计写入期间先等待文件操作完成。

## 新增算法：直接写一个 Python 文件

点击“组件管理”导入 `.py`，或打开目录放入文件，再刷新即可。不会生成模板或要求 JSON。
动态策略放到 `flexdmo_app/plugins/response_strategy/`，搜索算法放到
`flexdmo_app/plugins/search_algorithm/`；

- 动态策略实现 `response(population, problem, ...)`，可额外接收第三个 `algorithm`。
- 搜索算法实现 `step(population, problem, ...)`，返回完整下一代 Population 或二维决策矩阵。
  平台负责初始化、评价、环境响应、控制、快照和回放，不隐含添加 NSGA-II 选择。
- 普通类实现同样的方法，参数写在 `__init__`，不需要继承；完整优化循环可继承 Algorithm
  并实现 `optimize`。现有 JSON 文件夹式算法保持兼容。
- 参数从签名/默认值/类型注解读取；必填项提示，bool/Literal 自动用下拉框。
  自定义数值范围由算法代码检查，不根据参数名或正默认值猜测范围。
- 刷新只做 AST 解析，不执行导入、装饰器或默认值表达式。异常组件单独报告，不影响其他算法。
  真正运行拥有当前账户权限，不是安全沙箱；仅运行可信代码，不自动安装依赖。
- “检查并快速试跑”使用小规模 CDP1、独立子进程和 20 秒上限，不保存数据。
  默认参数可直接试跑，不多弹一次确认；必填参数才要求填写。
- 测试运行和批量实验共用一份实现。运行结果记录实际参数及执行代码的 SHA-256 指纹。
  代码修改后新进程读取新逻辑；接口或参数变动需刷新。错误堆栈给出文件和实际行号。

完整接口和短代码示例见 [CODE_API.md](CODE_API.md)。示例是接口演示，不冒充论文算法。

## 验证

```sh
# 使用原环境运行新适配层单元测试
.venv/bin/python -m unittest flexdmo_app.tests.test_core -v
.venv/bin/python -m unittest flexdmo_app.tests.test_experiments -v
# Qt 交互回归：参数保留、结果标题、缩放和工具栏导航
QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest flexdmo_app.tests.test_interactions -v
# 历史按钮、旧事件隔离、键盘、图表同步和主题回归
QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest flexdmo_app.tests.test_history -v
# 单文件算法：安全发现、参数推断、数值/输出检查、spawn、Qt 试跑和批量
QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest flexdmo_app.tests.test_code_plugins flexdmo_app.tests.test_code_ui -v
# macOS 原生 Cocoa 回放压力测试（不要设置 offscreen；默认不保存运行数据）
.venv/bin/python -m flexdmo_app.replay_smoke
# 单文件接入的原生 Qt 交互、检查超时和混合批量失败隔离
.venv/bin/python -m flexdmo_app.code_smoke
# 实际 Qt 事件循环与 spawn 子进程集成测试
QT_QPA_PLATFORM=offscreen .venv/bin/python -m flexdmo_app.smoke
QT_QPA_PLATFORM=offscreen .venv/bin/python -m flexdmo_app.batch_smoke
# 原版本回归测试
.venv/bin/python -m unittest discover -s tests
# 同问题预算分组、轻量历史和比较界面
QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest flexdmo_app.tests.test_comparison
# 在已有目录生成真实文档截图；演示结果仅在内存，不写运行数据
.venv/bin/python -m flexdmo_app.docs_capture --output /absolute/path/to/screenshots
```

旧 smoke 测试会在已有忽略规则覆盖的 `results/` 写测试图片和结果。
新增回放压力测试只使用内存；仅显式指定 `--capture <路径>` 才写截图。
它直接检查原生 Cocoa 无障碍方法，不申请系统权限；不能替代用户实际操作验证。

## 使用限制

目前使用源码启动，尚无正式安装包。高维 PF 是二维投影，高维 HV 未支持。
大规模运行仍使用算法内部历史，环境末帧只减少界面副本和文件。
默认无显著性检验；接口试跑和回归检查不等于论文算法验证。
